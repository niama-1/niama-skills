# niama-skills

个人 Skill 源仓库。

## 目录

- `skills/`：可被 Skill 管理器发现的 Skill
- `skills/niama-workflow/`：个人通用工作习惯 Skill

## 本地配置

将本仓库或 `skills/` 目录配置为 Skill 管理器的 Git 源。
具体安装目标由 Skill 管理器负责，不在仓库中硬编码。

## 日常更新

```powershell
git add .
git commit -m "update personal skills"
```

如果配置了远程仓库，再执行：

```powershell
git push
```
